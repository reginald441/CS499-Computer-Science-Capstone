Project overview

From an interactive dashboard to a stronger database-backed system.

The Grazioso Salvare project connects an interactive dashboard to MongoDB so users can search, filter, and visualize animal-shelter information through tables, charts, and map-based views.

I selected this artifact because it demonstrates the full path from application code to persistent data. The project combines a reusable Python CRUD module with a client-facing dashboard and shows how database choices affect usability, maintainability, performance, and security.

The original project already separated the MongoDB CRUD operations into a reusable module and connected that module to the dashboard. For the capstone enhancement, I focused on strengthening the database layer so the artifact demonstrates more advanced thinking about query performance, input validation, error handling, data safety, and secure access patterns.

Enhancement work

Key database improvements

The capstone enhancement builds on the original CS 340 client/server application while focusing specifically on stronger database engineering practices.

MongoDB indexing

Added indexing for frequently queried fields so repeated searches can be resolved more efficiently as the amount of stored data grows.

Safer query construction

Strengthened the way query values are accepted and validated to reduce the risk of unsafe or unintended NoSQL query behavior.

Input validation

Added checks around expected values and query inputs before database operations are performed, helping prevent invalid requests from reaching MongoDB.

Improved error handling

Expanded handling for failed operations, invalid results, and empty-result conditions so the application can respond more predictably.

More deliberate CRUD behavior

Reviewed create, read, update, and delete behavior with attention to clearer return values, safer single-record operations, and better control over database changes.

Performance and maintainability

Separated database concerns from dashboard presentation and documented the enhancement so future changes can be made without rewriting the entire application.

What I learned

Database design affects the entire application.

This enhancement showed me that database work is not only about storing information. Query structure, validation, indexing, error handling, and security choices directly affect how reliable and useful an application becomes.

I learned to think more carefully about the difference between a query that works on a small dataset and a query strategy that will continue to perform as the dataset grows. Indexes can improve common searches, but they also have costs and need to be selected intentionally.

I also strengthened my security mindset by treating user-controlled values as untrusted input. Validation and controlled query construction help protect the database while making failures easier to understand and troubleshoot.

Course outcome connection: This artifact demonstrates well-founded database techniques that deliver practical value while also addressing data validation, privacy, security, maintainability, and application reliability.
